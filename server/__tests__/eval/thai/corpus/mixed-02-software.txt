แนวปฏิบัติการจัดหาซอฟต์แวร์และการใช้ license

หน่วยงานอนุญาตให้ติดตั้งเฉพาะ software ที่อยู่ในบัญชีรายการที่ได้รับอนุมัติเท่านั้น การติดตั้งซอฟต์แวร์นอกบัญชีต้องยื่นคำขอพร้อมเหตุผลทางธุรกิจและผลการประเมินความเสี่ยงด้านความมั่นคงปลอดภัย

ทีม IT ตรวจสอบ license ที่ใช้งานจริงเทียบกับจำนวนที่ซื้อไว้ทุกไตรมาส หากพบว่าจำนวนการติดตั้งเกินจำนวนไลเซนส์ที่ถือครอง ต้องดำเนินการถอนการติดตั้งส่วนเกินหรือจัดซื้อเพิ่มภายในสามสิบวัน

ซอฟต์แวร์ประเภท open source ที่มีเงื่อนไขแบบ copyleft ห้ามนำมาใช้ในผลิตภัณฑ์ที่ส่งมอบให้ลูกค้าโดยไม่ผ่านการพิจารณาจากฝ่ายกฎหมาย เนื่องจากอาจมีผลผูกพันให้ต้องเปิดเผยซอร์สโค้ดของผลิตภัณฑ์

การต่ออายุ subscription ของซอฟต์แวร์ที่มีมูลค่าเกินหนึ่งแสนบาทต่อปี ต้องทบทวนความจำเป็นและเปรียบเทียบทางเลือกอย่างน้อยสองรายก่อนเสนออนุมัติ โดยแนบสถิติการใช้งานจริงย้อนหลังสิบสองเดือน
