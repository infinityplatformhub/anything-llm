คู่มือการขอสิทธิ์เข้าถึง API ภายใน

ทีมที่ต้องการเรียกใช้ internal API ต้องยื่นคำขอผ่านระบบ ticket โดยระบุ service ที่จะเรียก ปริมาณ request ต่อวินาทีที่คาดการณ์ และ environment ที่จะใช้งาน ทีม Platform จะพิจารณาภายในสองวันทำการ

ระบบออก API key ให้เป็นราย service ไม่ใช่รายบุคคล และ key มีอายุเก้าสิบวันนับแต่วันที่ออก ระบบจะส่ง email แจ้งเตือนก่อน key หมดอายุสิบสี่วัน หาก key หมดอายุแล้ว request ทั้งหมดจะได้รับ HTTP status 401 ทันทีโดยไม่มีช่วงผ่อนผัน

การ rotate key ต้องทำแบบ overlap คือสร้าง key ใหม่ก่อนแล้วให้ทั้งสอง key ใช้งานได้พร้อมกันเจ็ดวัน จากนั้นจึง revoke key เดิม ห้าม revoke key เดิมก่อน deploy code ที่ใช้ key ใหม่ครบทุก instance

ค่า rate limit เริ่มต้นคือหนึ่งร้อย request ต่อวินาทีต่อ key เมื่อเกินขีดจำกัดระบบจะตอบ HTTP status 429 พร้อม header ชื่อ Retry-After ที่ระบุจำนวนวินาทีที่ควรรอ ทีมที่ต้องการ limit สูงกว่านี้ต้องแนบผลการทดสอบ load test ประกอบคำขอ
