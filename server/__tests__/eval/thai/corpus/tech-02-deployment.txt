มาตรฐานการ deploy ระบบขึ้น production

ทุก release ต้องผ่าน staging environment อย่างน้อยยี่สิบสี่ชั่วโมงก่อนขึ้น production และต้องไม่พบ error ที่มีระดับความรุนแรง critical หรือ high ใน log ตลอดช่วงเวลาดังกล่าว

การ deploy ใช้รูปแบบ blue-green โดย traffic จะถูกเปลี่ยนไปยัง environment ใหม่ทีละขั้น เริ่มที่ห้าเปอร์เซ็นต์ จากนั้นยี่สิบห้าเปอร์เซ็นต์ และหนึ่งร้อยเปอร์เซ็นต์ โดยเว้นระยะแต่ละขั้นไม่น้อยกว่าสิบห้านาที

เงื่อนไขการ rollback อัตโนมัติคือ error rate เกินหนึ่งเปอร์เซ็นต์ของ request ทั้งหมด หรือ latency ที่ percentile ที่เก้าสิบเก้าเกินสองวินาที ติดต่อกันเกินห้านาที ระบบจะย้อน traffic กลับไปยัง environment เดิมโดยไม่ต้องรอการอนุมัติจากมนุษย์

ห้าม deploy ขึ้น production ในวันศุกร์หลังเวลาสิบห้านาฬิกา และห้าม deploy ในช่วง freeze period ที่ประกาศล่วงหน้า เว้นแต่เป็นการแก้ไข incident ระดับ severity หนึ่งซึ่งต้องได้รับอนุมัติจาก on-call lead
