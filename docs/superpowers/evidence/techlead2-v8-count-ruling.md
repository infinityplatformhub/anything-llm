# Techlead-2 — V8: การนับ 77 vs 10 และ ruling เรื่อง scope

**Dev4 ถูก ผมผิด** — และวิธีนับของผมผิดในทางที่ทำให้ประเมินงานต่ำเกินไป

---

## ทำไมผมได้ 10

ผมกรองด้วย `grep -v` ที่ตัด `className|style|md:|<|render|return|import|const|?|&&` ออก ·
**`-v ?` ตัดทุก ternary ทิ้ง** และ **`-v style` ตัดทุก inline style ทิ้ง** · เหลือแค่
`if (isMobile)` แบบเปล่า ๆ 10 บรรทัด

**นั่นไม่ใช่ "การใช้ที่เป็น layout ทั้งหมด" มันคือ "การใช้ที่ไม่ใช่ ternary และไม่อยู่ใน style"**
· ผมรายงานตัวเลขนั้นว่าเป็นอย่างแรก · **ข้อสรุปที่ผมสร้างจากมัน ("ทั้ง 10 แห่งเลือก
layout") จริงในตัวมันเอง แต่ฐานที่นับผิด**

ผมวัดใหม่:

```
บรรทัดที่มี isMobile ไม่รวม import:  79  (Dev4: 78 — ต่างเพราะ comment/test filter)
ไฟล์:                                52  (Dev4: 51)
ใน className:                         1  (ตรงกัน)
```

**ตัวเลขของ Dev4 ถูก** · ความต่าง 1 มาจาก comment stripping ซึ่งเป็นวิธีที่ถูกกว่า

## แต่ข้อสรุปหลักของผมไม่เปลี่ยน — และตอนนี้แข็งกว่าเดิม

ผมแยกทั้ง 78 ตามรูปทรง:

```
58  ternary ที่ให้ค่า string   (52 height, 3 width, 1 className)
11  if (isMobile) fork ต้นไม้
 7  isMobile && conditional render
 0  อ้างถึง touch / pointer / swipe / hover / tap / gesture
```

**ศูนย์ — ไม่ใช่ "น้อย"** · การกรองด้วยคำที่เกี่ยวกับ touch ทั้งหมดบน 78 บรรทัดได้ 0 ·
**ข้อสรุป "ไม่มีอะไรให้เก็บไว้เป็น UA" ยังจริง และตอนนี้วัดบนฐานที่ถูก**

## สิ่งที่ฐานที่ถูกเปิดเผย และเปลี่ยน ruling scope ของผม

นับ **expression ที่แตกต่างกันจริง** ไม่ใช่บรรทัด:

```
52 ครั้ง  isMobile ? "100%" : "calc(100% - 32px)"      <- ใน 40 ไฟล์
 3 ครั้ง  isMobile ? "w-full" : "min-w-[360px] w-fit"
 1 ครั้ง  isMobile ? "88%" : "25%"
 1 ครั้ง  isMobile ? "70%" : "45%"
 1 ครั้ง  isMobile ? "55%" : "30%"
```

**58 จาก 78 การใช้ คือ 5 expression** · และ **52 ในนั้นคือ expression เดียวกันเป๊ะ
คัดลอกไป 40 ไฟล์**

**นี่ไม่ใช่ 71 การตัดสินใจที่ค้างอยู่ มันคือ 1 การตัดสินใจที่ถูกคัดลอก 52 ครั้ง**

`height: 100%` vs `calc(100% - 32px)` — ตัวเลข 32px คือความสูงของแถบอะไรสักอย่างที่
ไม่มีบนมือถือ · **คำถามเดียว ตอบครั้งเดียว ใช้ได้ 40 ไฟล์**

## RULING scope — **แก้ที่ต้นทางของการคัดลอก ไม่ใช่รับ 71 site เป็น residual**

ผมเปลี่ยนคำสั่งจากที่เขียนไว้รอบก่อน:

**(ก) สามพื้นผิว ตามเดิม**

**(ข) เพิ่ม: แปลง `height` idiom ทั้ง 52 ครั้งใน slice เดียว** — ไม่ใช่เพราะ "แปลงเยอะดี"
แต่เพราะ **มันคือการตัดสินใจเดียว** · การรีวิว 40 ไฟล์ที่มี diff บรรทัดเดียวเหมือนกันหมด
ราคาต่ำกว่าการรีวิว 1 ไฟล์ที่มี 9 การตัดสินใจ · และมันหด residual จาก 71 เหลือ ~19

วิธีที่ถูกคือ **ไม่ใช่แทนที่ `isMobile` ด้วย hook ใน 52 ที่** แต่คือ **ยกออกเป็น CSS
class เดียว** (`h-full md:h-[calc(100%-32px)]`) — ลบทั้ง inline style และการพึ่ง JS
พร้อมกัน · **หนึ่ง utility ใน Tailwind ตอบคำถามนี้ได้ทั้งหมด** และ CSS คือที่ที่คำถาม
"มีที่ว่างเท่าไร" ควรถูกตอบอยู่แล้ว

**(ค) ที่เหลือ ~19 site (11 `if` fork + 7 `&&` + 4 ternary ที่ไม่ใช่ idiom หลัก)
เป็น residual ที่ระบุไฟล์ได้** — แต่ละอันเป็นการตัดสินใจจริงที่ต้องดูทีละอัน ·
**นี่คือ residual ที่ผมรับ** ต่างจาก 71 ที่ 52 ในนั้นไม่ใช่การตัดสินใจเลย

## lint rule — ยังยืนตามเดิม แต่แก้เป้าหมาย

ผมเคยสั่ง "กัน import ใหม่ พร้อม allowlist" · Dev4 ชี้ถูกว่า lint กันได้แค่ import ใหม่ ·
**ยังคุ้ม** เพราะ allowlist ที่ระบุไฟล์ทำให้ residual **หดลงได้และวัดได้** แทนที่จะเป็น
ข้อความที่คนลืม · แต่ **หลัง (ข) allowlist จะเหลือ ~19 ไฟล์ไม่ใช่ 71** ซึ่งเป็นรายการที่
คนอ่านแล้วรู้สึกว่าปิดได้จริง

## `usePrefersDarkMode` — Dev4 ถูกและตรงกว่าที่ผมเขียน

ผมเขียนว่า "ใช้ `matchMedia` แต่อ่านครั้งเดียว ไม่ subscribe" · **Dev4 ชี้ว่ามันไม่ใช่
hook เลย** — ไม่มี `useState` ไม่มี `useEffect` เป็นฟังก์ชันธรรมดาที่ตั้งชื่อขึ้นต้นด้วย
`use` · **แม่นกว่า** และอธิบายว่าทำไมมันไม่ re-render: ไม่ใช่เพราะลืม subscribe
แต่เพราะไม่มีอะไรจะ subscribe **เข้า** · do-not-copy ตามที่ Dev4 เสนอ

## สรุป

- **การนับของ Dev4 ถูก ของผมผิด** — ผมกรอง `?` และ `style` ออกโดยไม่ตั้งใจ
  แล้วรายงานผลว่าเป็นจำนวนการใช้ที่เป็น layout ทั้งหมด
- **ข้อสรุป viewport ไม่เปลี่ยน** — 0/78 บรรทัดอ้างถึง touch semantics บนฐานที่ถูก
- **แต่ scope เปลี่ยน**: 52 ของ 78 คือ expression เดียวคัดลอก · แปลงมันเป็น Tailwind
  class ใน slice เดียว แล้ว residual เหลือ ~19 ที่เป็นการตัดสินใจจริง
- **ไม่รับ residual 71 site** — เพราะ 52 ในนั้นไม่ใช่การตัดสินใจ มันคือการคัดลอก
