## `SIG_SALT`

- The generated value does **not** appear anywhere in the doctor's output
  (grepped the captured output for the literal value: 0 occurrences).
- `secrets.present` reads the process environment as well as the `.env` file:
  with an empty `.env` and the four keys supplied only through the environment it
  reports `PASS`; drop `SIG_SALT` from both and it reports
  `Missing instance secret(s): SIG_SALT.` — naming the key, never its value.

That second behaviour is what makes the check correct under the entrypoint, where
`.env` has already been loaded into the environment by the time the doctor runs.
