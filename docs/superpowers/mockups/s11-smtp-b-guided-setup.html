S11 mockup B — guided setup, then a status page

Throwaway mockup for step 1.5. The difference from A: you cannot save a configuration that has never sent a message. Step 2 has to pass before step 3 unlocks, so “saved” and “working” are the same state. Try it — the test fails until a host is filled in.

    1 · Connection

    Encrypted at rest; never shown again.

    Plaintext. The SMTP password and every message — invite links included — cross the network unencrypted, readable by anything on the path. Refused unless SMTP_ALLOW_INSECURE is set on the server, and logged loudly at every boot.
    Tick the box above to continue with an unencrypted connection.

    2 · Send a real message

    This must succeed before the configuration can be saved. A mail server that was never exercised is a broken invite discovered by whoever it was sent to.
