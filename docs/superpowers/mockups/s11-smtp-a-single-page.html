S11 mockup A — SMTP settings on one page

Throwaway mockup for step 1.5. Config, connection test and the send log live on a single scrolling page, the way GeneralSettings/Security does. Everything below is clickable: try saving with a blank host, testing the connection, and switching the encryption mode to none.

Email delivery

Used for invitations. Nothing else sends mail yet.

A host is required.

Stored encrypted (AES-256-GCM). It is never shown again after saving, and never returned by the API.

Plaintext. The SMTP password and every message, including invite links, cross the network unencrypted. Refused unless SMTP_ALLOW_INSECURE is set on the server, and logged loudly at every boot.

Recent deliveries

Status only. Subjects, bodies and invite links are never recorded here — an invite link in a log is a working credential.

When Recipient Template Status
queued means the server accepted the message. SMTP cannot confirm it reached a mailbox, so no row ever says “delivered”.
