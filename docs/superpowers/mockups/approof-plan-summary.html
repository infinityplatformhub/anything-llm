ApproofWorkspace

Local AI workspace สำหรับองค์กรไทย — fork จาก AnythingLLM เติมชั้น enterprise ให้ครบ ขายได้ทั้ง SME 20–200 คน และ regulated (ธนาคาร / รพ. / ราชการ)

ระยะเวลา ~7 เดือน ราคา per-seat DB Postgres ตั้งแต่ต้น LLM hybrid local + cloud PDPA pattern-based redaction งานทั้งหมด 41 items

02 Core seams — "ปลั๊ก + เต้ารับ"

กันการรื้อ: ตีเส้น interface 8 จุดก่อนสร้างฟีเจอร์ การเชื่อมต่อใหม่ในอนาคต = เขียน driver เพิ่ม ไม่ผ่า core เกณฑ์ปิด: ทุก use case ต้องวาด sequence diagram ผ่าน seams ได้ก่อน fan-out

SEAM 1Identity providerOIDC / SAML / LDAP / Lark
SEAM 2Authorization engineเช็คสิทธิ์จุดเดียวทั้งระบบ
SEAM 3Chat pipelineredaction → guardrails → metering
SEAM 4Connector SDKDrive / Lark Docs / อนาคต
SEAM 5Channelweb / Lark bot / embed widget
SEAM 6Notificationemail / Lark / webhook
SEAM 7Vector DB + ACL filterสิทธิ์กรองใน query contract
SEAM 8License gateper-seat enforce จุดเดียว
Core services กลาง: job queue + scheduler (sync, retention, backup) และ event bus (ทุก action ยิง event → audit เก็บอัตโนมัติ ครบไม่มีหลุด)

04 สองเลนขนาน

Track S — Security · Identity · Governance

ผ่าน procurement + ขาย regulated ได้

  • S1–3SSO: OIDC generic → SAML → LDAP (จำกัด domain, กัน lockout)
  • S4Lark org sync — ผู้ใช้/แผนก → workspace/role
  • S5Audit append-only + export SIEM + eDiscovery
  • S6Retention · PDPA redaction · consent modal · DLP scan · emergency hide · temporary chat
  • S7LLM policy ต่อ workspace + model catalog ต่อ group
  • S8Guardrails + runtime policy agent tools + web-search governance
  • S9Air-gap switch ตัด outbound ทั้งหมด
  • S10Analytics + token budget enforcement
  • S11SMTP/mailer
  • S12Offboarding + โอนข้อมูล
  • S13MFA · session control · backchannel logout

Track V — Product Value

ทำให้คนใช้จริง + demo ที่ขายได้

  • V1ภาษาไทยครบวงจร — UI · Thai embedding · OCR สแกน
  • V2Lark bot ถาม AI ในแชท (= คำตอบ mobile)
  • V3Connectors: Google Drive + Lark Docs + health UI
  • V4Assistant templates + sharing + versioning + library
  • V5Citation · feedback · eval harness ไทย
  • V6แชร์บทสนทนาในทีม
  • V7Embed widget (harden เข้า scoped keys)
  • V8Responsive mobile web
  • V9ค้นหาประวัติแชท
  • V10Org-wide document search แบบ Google + filters
  • V11RAG tuning admin + reindex จาก UI

Wave 2 — เริ่มเดือน 4–5

  • V12Image generation (local/cloud ตาม S7 policy)
  • V13Knowledge curation — Answers · Collections · Pins
  • V14Deep research (เปิดได้เมื่อ S10 budget + O6 queue เสร็จ)
  • V15Code interpreter ใน sandbox แยกขาด — ปิด default, security-review แยก

Ops — ขายซ้ำได้ ไม่ใช่ project ครั้งเดียว

แทรกเดือน 3–5

  • O1License per-seat — นับ active user, ทำงาน offline/air-gap ได้
  • O2Installer / setup wizard
  • O3Backup/restore ในตัว พิสูจน์ restore ได้จริง
  • O4Model lifecycle — GPU sizing, update bundle, re-embed workflow
  • O5Diagnostic bundle + Prometheus metrics
  • O6GPU queue + UI "รอคิว" (POC ช้า = ขายไม่ได้)
